# VintedBot Context

Ce fichier permet de garder une trace des choix d'architecture et des mécanismes critiques.

## Filtres et Limites de requêtes
- **Tri Vinted (`order=newest_first`)** : Toutes les URL surveillées doivent inclure ce tri pour éviter les vieilles annonces.
- **Cache mémoire (1000 items)** : L'API de Vinted a tendance à mélanger légèrement les annonces sur la première page à cause de problèmes de cohérence (ElasticSearch). Pour éviter que le bot n'oublie une annonce qui recule en page 2 puis revient en page 1, on garde les 1000 derniers ID en mémoire (`cogs/sniper.py`).
- **Timestamp des annonces** : L'API Vinted ne donne pas l'heure de publication exacte sans charger la page web complète. À la place, on utilise le timestamp de la photo principale (`photo.high_resolution.timestamp`), qui correspond à l'heure d'upload de la photo. La limite ignorant les annonces dont la photo a plus de 60 minutes a été retirée afin de toujours analyser les annonces, même en cas de délai important entre l'upload de l'image et la publication.
- **Filtres IA sur les pièces détachées et anciennes consoles** : L'IA est entraînée pour chasser des annonces très rentables ou en panne. Pour éviter que des coques vides ou des boîtes de manette soient confondues avec de vraies manettes très peu chères, des instructions strictes (`À FUIR`) ont été ajoutées dans le prompt texte (`critere.md`) et le prompt de validation visuelle (`utils/gemini.py`). De plus, ces mêmes prompts intègrent des règles anti-faux positifs pour les anciennes consoles Nintendo (ex: rejet de la Nintendo 2DS classique plate qui porte à confusion si vendue avec le jeu "New Super Mario").
- **Parsing API URL** : Le site Vinted utilise des crochets dans ses URL de recherche (`catalog[]`, `brand_ids[]`). L'API Vinted (v2) requiert des paramètres sans crochets et renomme certains (`catalog` devient `catalog_ids`). Le client Vinted (`utils/vinted.py`) nettoie et traduit dynamiquement ces paramètres avant d'appeler l'API pour s'assurer que les filtres de catégorie sont respectés, évitant que Vinted ne renvoie des résultats hors-sujet comme des vêtements.
- **Suspension de Surveillance (Toggle)** : Les configurations de surveillances en mémoire et en base de données stockent un booléen `is_active` (`utils/database.py`). Le sniper Vinted (`cogs/sniper.py`) ignore silencieusement les URLs désactivées pour éviter toute requête API inutile. L'utilisateur peut activer/désactiver à la volée ses surveillances via `/vinted_toggle`.
- **Fast Track & Vision IA** : Le système Fast Track (alerte immédiate pour les articles entre 9€ et 21€) envoie l'alerte instantanément, puis effectue une analyse sémantique (texte) puis **visuelle (image)** en asynchrone (`cogs/sniper.py`). Si l'image révèle un produit "À FUIR" (ex: fausse manette), le message Discord précédemment envoyé est automatiquement supprimé.
